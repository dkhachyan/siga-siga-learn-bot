# Σιγά σιγά

Telegram-бот для изучения греческих слов через короткие разговоры.

Загружаешь пачку слов — фотографией конспекта или текстом. Бот превращает её в учебный материал и в течение заданного периода несколько раз в день пишет тебе короткие диалоги, в которых эти слова нужно употребить. Не карточки и не тесты — переписка с собеседником, который замечает ошибки и мягко их исправляет.

Название — греческое «σιγά σιγά», «потихоньку». Оно же и обещание: не выучить язык за месяц, а не бросить.

**Бот:** [@SigaSigaLearnBot](https://t.me/SigaSigaLearnBot)

## Статус

Этап 0 из [спецификации](SPEC.md): каркас. Бот отвечает на `/start` и `/help` и заводит пользователя в базе — больше пока ничего. Слова, диалоги и расписание идут дальше по этапам.

## Что умеет (по спецификации)

- Импорт слов фотографией (печать и рукопись) или текстом, с обязательным экраном подтверждения
- Разговорные эпизоды: 4 в день по 2–4 реплики, вокруг 1–3 целевых слов
- Постоянный собеседник с памятью о предыдущих разговорах
- Исправление рекастом — переспросом в правильной форме, без разрыва диалога; полный разбор по кнопке
- Расписание: свой период изучения, частота и окно, в которое боту можно писать
- SRS: сложные слова возвращаются чаще, выученные реже
- По окончании периода — отчёт, перенос невыученных слов и запрос новой пачки
- Режим повторения всего архива

## Стек

Python 3.12 · aiogram 3 · PostgreSQL 16 · SQLAlchemy 2 + Alembic · Anthropic API · Docker Compose

Пакетами и виртуальным окружением заведует [uv](https://docs.astral.sh/uv/).

## Запуск

Нужен токен бота от [@BotFather](https://t.me/BotFather) — без него приложение не стартует и скажет об этом.

```sh
cp .env.example .env      # и вписать BOT_TOKEN
```

### В контейнерах

```sh
make up      # поднимает Postgres, накатывает миграции, запускает бота
make logs
make down
```

### Локально, с базой в Docker

Удобнее для разработки: код перезапускается без пересборки образа.

```sh
make install   # uv sync
make db        # только Postgres
make migrate
uv run python -m siga
```

По умолчанию `BOT_MODE=polling` — публичный адрес не нужен, бот сам ходит за апдейтами.

### На сервере

`BOT_MODE=webhook` плюс `WEBHOOK_BASE_URL` (https) и `WEBHOOK_SECRET`. Бот поднимает свой HTTP-сервер на `WEBHOOK_PORT`, TLS терминирует Caddy или другой обратный прокси перед ним. Здоровье процесса — `GET /health`.

## Разработка

```sh
make check      # ruff format + ruff check + mypy + pytest
make fmt        # отформатировать и починить, что чинится
make revision m="описание"   # новая миграция по изменённым моделям
```

То же самое гоняет CI на каждый push и pull request, плюс отдельной задачей проверяет, что миграции накатываются, откатываются и не разошлись с моделями.

## Как устроен код

```
src/siga/
  bot/        хендлеры, мидлвари, тексты интерфейса — весь Telegram живёт тут
  core/       домен: SRS, раскладка слотов, правила оценки, жизненный цикл эпизода
  llm/        Anthropic API: клиент, схемы, промпты, учёт токенов
  workers/    scheduler-worker и sender-worker
  db/         модели, сессии, запросы
  config.py   единственное место, читающее окружение
  runner.py   запуск: polling или webhook
migrations/   Alembic
```

`core/` намеренно не знает про aiogram, anthropic и SQLAlchemy — это чистая логика, которая тестируется без базы и сети. Проверяется тестом, а не только договорённостью.
